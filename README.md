# Adventure in vivo

## 作品概要

人間が巨大な生物の体内に入り、病原体と戦う2D横スクロールシューティングゲームです。

Unityの学習をきっかけに制作を開始し、1ステージのゲームとして完成させ、Unityroomで公開しています。

## 開発環境

* Unity
* C#
* EDGE
* 開発期間：約1か月

## 実装内容

* 2D横スクロール
* プレイヤーの移動
* 弾の発射
* 敵キャラクター
* ボス戦
* ボス撃破・落下アニメーション
* 効果音
* ゲームクリア処理

## 制作について

ゲームとして完成させることを目標に、プレイヤーの操作から敵・ボスとの戦闘、ゲームクリアまでの一連の流れを実装しました。

背景や敵キャラクターなどの2D素材はEDGEを使用して制作しています。
